# Contributing Guidelines

We welcome contributions to the Enterprise AI Knowledge Management Platform. Please review the rules below:

## 1. Branching Strategy
We use GitHub Flow:
* Fork the repo and create your branch from `main`: `feature/your-feature-name`.
* Keep branch lifecycles short.

## 2. Commit Format
Commits must follow Conventional Commits formatting:
* `feat:` a new feature.
* `fix:` a bug fix.
* `docs:` updates to documentation.
* `refactor:` code restructuring.

## 3. Pull Request Requirements
* Link to a tracked GitHub issue.
* Pass automated linting and unit testing.
* Require at least one approving review.
